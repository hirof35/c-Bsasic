Computational Geometry & Puzzle Engine (C++)本プロジェクトは、計算幾何学の基礎である「線分の交差判定」の実装と、高機能C++フレームワーク OpenSiv3D を用いた「15パズル」のゲームエンジンを同梱した技術デモです。技術的特徴1. 線分交差アルゴリズム (Segment Intersection)2つの線分 $P_1Q_1$ と $P_2Q_2$ が交差するかどうかを、向き（Orientation）判定を用いて判定します。外積の応用: 3つの点の位置関係（時計回り、反時計回り、共線）を外積（Cross Product）の性質を利用して算出。判定ロジック: $P_1Q_1$ に対して $P_2$ と $Q_2$ が異なる側にあり、かつ $P_2Q_2$ に対して $P_1$ と $Q_1$ が異なる側にある場合に交差とみなします。2. 数学的に保証された15パズル (Siv3D Engine)直感的なUIと、数学的に「解ける」盤面生成ロジックを搭載しています。解法可能性の判定 (Inversion Count):15パズルは完全にランダムな配置にすると50%の確率で「絶対に解けない」状態になります。本エンジンでは生成時に転倒数（Inversions）を計算し、偶奇性をチェックすることで、ユーザーが必ずクリアできる盤面のみを提供します。グリッド制御: 2次元配列（Array of Array）による効率的なタイル状態管理。インタラクティブ操作: マウス座標からタイルインデックスへの動的変換と、マンハッタン距離を用いた隣接移動制限。セットアップと実行依存関係C++ コンパイラ: C++17 以上フレームワーク: OpenSiv3D (v0.6.x 推奨)ビルド手順OpenSiv3D のプロジェクトテンプレートをダウンロード。Main.cpp にソースコードを配置。IDE（Visual Studio 等）でビルドを実行。操作方法タイルの移動: 空白に隣接するタイルを左クリック。クリア条件: タイルを 1 から 15 まで順番に並べ、右下を空白にする。システム構成言語: C++幾何判定ロジック: orientation(), doIntersect()ゲームロジック:initializePuzzle(): 初期化・シャッフルisSolvable(): 数学的クリア可否判定isSolved(): 勝利判定ライセンスMIT License <img width="1476" height="753" alt="スクリーンショット 2026-05-10 125749" src="https://github.com/user-attachments/assets/53a3b442-ebef-454d-a912-82f566154ec3" />
